Home Server Backups

Личное приложение владельца GitHub-аккаунта Hargas-creator для резервного копирования собственного домашнего сервера в свой Google Диск. Приложение предназначено для одного владельца; регистрация других пользователей не предусмотрена. Подключение и проверка резервного копирования находятся на этапе настройки.

Приложение создаёт зашифрованные резервные копии, сохраняет их в отдельной папке Google Диска и позволяет скачать их для восстановления. Содержимое архивов и имена файлов внутри хранилища резервных копий шифруются на сервере перед отправкой. Для расшифровки владельцу нужна отдельно сохранённая информация восстановления.

Доступ к Google Диску запрашивается через разрешение drive.file: приложение работает с файлами, созданными им или явно предоставленными ему владельцем. Для резервного копирования используются только собственная папка и созданные приложением копии. Доступ ко всему содержимому Диска не запрашивается.

Эта страница содержит описание приложения. Вход в Google и согласие на доступ происходят только на страницах Google. Эта страница не принимает пароли, токены или файлы.

Политика конфиденциальности

Владелец приложения: Hargas-creator. Контактный адрес поддержки указан в окне согласия Google для Home Server Backups.
