Home Server Personal Assistant

Личный помощник владельца GitHub-аккаунта Hargas-creator. Приложение работает на собственном сервере владельца через OpenClaw и gog. Оно предназначено для одного владельца, а не для регистрации сторонних пользователей.

По поручению владельца помощник ищет и читает письма Gmail, события Google Календаря и файлы Google Диска. Явные поручения могут включать отправку писем, создание и изменение событий, загрузку и изменение файлов. Административные права Google Workspace приложению не предоставляются.

Вход и согласие на доступ выполняются только на страницах Google. Этот сайт содержит описание приложения; здесь нет формы входа, приёма паролей или загрузки пользовательских данных.

Выбранные для ответа сведения могут обрабатываться поставщиком используемой ИИ-модели, а ответы — передаваться владельцу через Telegram. Подробности хранения, передачи и отзыва доступа описаны в политике конфиденциальности.

Владелец приложения: Hargas-creator. Контакт для вопросов об этом приложении: адрес поддержки, указанный на экране согласия Google.
