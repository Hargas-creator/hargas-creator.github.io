Политика конфиденциальности Home Server Backups

Обновлено: 23 сентября 2026 года.

Home Server Backups — личное приложение владельца GitHub-аккаунта Hargas-creator для зашифрованного резервирования своего сервера в своём Google Диске. Настоящая политика описывает его предусмотренную работу после подключения. Другие пользователи к приложению не подключаются.

Какие данные используются и зачем

Приложение использует Google OAuth и разрешение drive.file, чтобы создавать папку резервных копий, загружать архивы и служебные файлы проверки, получать сведения об этих файлах, скачивать их для восстановления и удалять устаревшие копии. Для резервирования приложение работает только с созданной им папкой и своими файлами; общий доступ к Диску не запрашивается.

Приложение получает и хранит токены авторизации для выполнения этих действий без повторного входа перед каждой копией. Пароль Google приложению не передаётся. Идентификаторы, размеры и даты файлов используются для проверки загрузки и управления сроком хранения. Данные, полученные через Google API, используются только для резервного копирования и восстановления.

Хранение и защита

Архивы шифруются на сервере до отправки в Google Диск. Имена файлов внутри зашифрованного хранилища также шифруются. Google Диск хранит зашифрованные файлы и технические сведения о них, включая размеры и время операций; шифрование не скрывает эти сведения.

Рабочие учётные данные и ключи хранятся в закрытых конфигурационных файлах на устройствах владельца, где выполняется настройка и резервирование. Владелец отдельно сохраняет информацию для восстановления доступа и расшифровки. Она не публикуется на этом сайте и не включается в зашифрованные копии как единственный способ восстановления. При восстановлении расшифрованные данные обрабатываются в выбранной владельцем среде.

План хранения — до семи успешных ежедневных копий и четырёх недельных. Устаревшие копии удаляются после создания и проверки новой успешной копии. Удаление по этому правилу окончательное, без перемещения в корзину Google Диска. При сбоях удаления данные могут храниться дольше; владелец может удалить их вручную.

Передача данных

Google обрабатывает зашифрованные файлы и сведения об операциях как поставщик Google Диска. Если включены уведомления в Telegram, в личный чат владельца передаётся только состояние резервирования; содержимое архивов, ключи и токены в уведомления не включаются.

Данные Google не продаются, не используются для рекламы или обучения моделей и не передаются другим лицам для этих целей. Использование данных, полученных через Google API, и их передача другим приложениям соответствуют Google API Services User Data Policy, включая требования Limited Use.

Отзыв доступа и удаление

Владелец может отключить приложение в настройках подключений Google-аккаунта, остановить расписание резервирования и удалить папку резервных копий в Google Диске. Отзыв OAuth-доступа сам по себе не удаляет уже сохранённые файлы. Локальные конфигурации и информацию восстановления владелец удаляет отдельно, когда они больше не нужны.

Эта информационная страница

На страницах нет форм, рекламных инструментов или подключённой приложением аналитики. Хостинг GitHub Pages может сохранять IP-адреса посетителей для безопасности сервиса согласно политике конфиденциальности GitHub. Сайт не принимает данные Google-аккаунта или содержимое резервных копий.
